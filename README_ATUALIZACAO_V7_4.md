# Atualização V7.4 — Fluxo de Caixa em formato desktop

## Alterações
- Tela principal do Fluxo de Caixa redesenhada para uso em desktop/ERP.
- Box compacto de filtros com período, conta, categoria e tipo.
- Barra de ações com lançamento, transferência, importação, contas e plano de contas.
- Cards de resumo financeiro mais compactos.
- Grid principal com cabeçalho fixo e colunas separadas para Entrada e Saída.
- Busca instantânea dentro do grid já filtrado.
- Ações por linha mais compactas e classificação em popover.
- Painéis de saldos, resumo diário e categorias organizados abaixo da grade.
- Tela de lançamento/edição redesenhada em boxes, com resumo lateral.
- Categoria continua sendo escolhida apenas pelo subgrupo; o grupo é automático.
- Botão “Salvar e novo” para lançamentos manuais em sequência.
- Layout responsivo para celular.

## Banco de dados
Nenhuma alteração de schema é necessária.
