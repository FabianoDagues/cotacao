# Atualização V7.3 — Categorias simplificadas e edição do plano de contas

## O que mudou
- Lançamentos e edições financeiras agora escolhem somente **Categoria/Subgrupo**.
- O **Grupo principal** é inferido automaticamente pelo vínculo do subgrupo.
- Classificação de lançamentos importados também usa um único seletor de categoria.
- Filtros do Fluxo de Caixa usam um único campo **Categoria**, permitindo selecionar:
  - o grupo inteiro (`Grupo — todos`); ou
  - um subgrupo específico.
- Tela **Plano de contas** redesenhada em cartões por grupo.
- Edição de grupo e subgrupo na própria tela.
- Inclusão de subgrupo diretamente dentro do grupo, sem escolher o grupo de novo.
- Busca rápida por grupo/subgrupo.
- Ativar/desativar continua disponível.
- Subgrupos com o mesmo nome podem existir em grupos diferentes; nomes duplicados dentro do mesmo grupo continuam bloqueados.
- Entradas/saídas manuais não podem ser salvas sem categoria.

## Banco de dados
Nenhuma tabela nova é necessária. A atualização usa a estrutura já existente.
